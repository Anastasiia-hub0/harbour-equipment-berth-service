# SAAD71000 CA1: Harbour Equipment and Berth Service

Individual requirements and domain analysis for scenario CA1-24-HEBS (Kerry Harbour Services Cooperative).

## Status

Complete. The final report is report/CA1-report.pdf. The CA1 release is tagged in GitHub.

## Report sections

* Section 1: Scenario interpretation (evidence, problems, problem statement)
* Section 2: Purpose, scope and boundary
* Section 3: Stakeholders and actors
* Section 4: Functional and non-functional requirements
* Section 5: Rules and uncertainty register (rules, risks, assumptions, constraints, questions)
* Section 6: Use-case model (catalogue, diagram, detailed use case UC04 Allocate Berth)
* Section 7: Gherkin examples (GH01 to GH04)
* Section 8: Candidate concepts and glossary
* Section 9: Domain model
* Section 10: Traceability matrix
* Section 11: Reflection and AI declaration
* References
* Appendix A: User stories and acceptance criteria

## Folders and files

* report/: the full report and a separate file for each section
* diagrams/: PlantUML source (.puml) and image (.png) for the use-case model and the domain model
* features/: Gherkin feature file (allocate-berth.feature)
* requirements/: where the requirements, user stories and traceability are in the report
* decisions/: the main analysis decisions and where they are explained
* references/: the original scenario document 
* ai-log.md: AI interaction log
